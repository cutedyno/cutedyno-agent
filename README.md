# CuteDyno agent skills

Install the CuteDyno CLI and agent skill:

```bash
npm install -g cutedyno
npx skills add cutedyno/cutedyno-agent
```

- Hosted MCP: `https://api.cutedyno.com/mcp` (Bearer API key)
- Stdio MCP: `npx -y cutedyno mcp`
- CLI docs: https://cutedyno.com/docs/cli
- Agent landing: https://cutedyno.com/agent

This repository is synced from [cutedyno/cutedyno](https://github.com/cutedyno/cutedyno).
